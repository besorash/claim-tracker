# ربط التطبيق مع جوجل شيت

مزامنة يدوية في الاتجاهين: تضغط **الإعدادات ← جوجل شيت ← مزامنة الآن**.

## التجهيز (مرة وحدة)

1. افتح الشيت ← **Extensions ← Apps Script**.
2. امسح الموجود والصق محتوى `Code.gs` كامل، ثم احفظ.
3. من القائمة فوق اختر الدالة `setup` واضغط **Run**. وافق على الصلاحيات (حسابك أنت).
   - بيتضاف عمود `updated_at` في آخر الشيت. لا تمسحه.
   - افتح **Execution log** وانسخ **مفتاح المزامنة** اللي يطلع.
4. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط Deploy وانسخ رابط **Web app URL** (ينتهي بـ `/exec`).
5. في التطبيق: **الإعدادات ← جوجل شيت ← إعدادات الربط**، حط الرابط والمفتاح واحفظ.

بعدها اضغط **مزامنة الآن**.

## القواعد

- الصف الأول لازم يظل بأسماء الأعمدة الإنجليزية (`id`, `customer_name`, ...).
- سطر جديد في الشيت: خل `id` فاضي. يكفي تعبّي خانة وحدة (مثلاً رقم المطالبة)، والتطبيق يكتب الرقم في `id` بعد المزامنة.
- لا تعدّل خانة `id` بيدك.
- الحذف من التطبيق بس. لو مسحت سطر من الشيت، يرجع في المزامنة الجاية.
- لو تعدّلت نفس المطالبة في المكانين بين مزامنتين، يمشي التعديل الأحدث.
- أول مزامنة: لو فيه اختلاف بين الشيت والتطبيق، الشيت هو اللي يمشي.

## لو عدّلت `Code.gs` بعدين

**Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**. الرابط يظل نفسه.

لو انسرق المفتاح: شغّل `setup` مرة ثانية وحط المفتاح الجديد في التطبيق.
